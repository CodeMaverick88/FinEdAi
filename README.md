# FinEdAI - AI Funding Support Agent

FinEdAI is an AI-powered assistant designed to help Kenyan students navigate educational funding, analyze financial statements (M-Pesa/Bank statements), generate tailored HELB/HEF appeal letters, and match with bursaries and scholarships.

## Tech Stack
- **Frontend**: React + Vite, React Router DOM, Lucide Icons
- **Backend**: Node.js, Express.js
- **Database**: PostgreSQL (Neon Serverless)
- **Deployment**: Vercel

## Structure
- `client/`: React Frontend Application
- `server/`: Express API & AI Services
